# FirstAid AI - Trợ lý Sơ cứu Y tế Khẩn cấp & Điều phối Hỗ trợ Cộng đồng

Hệ thống hỗ trợ sơ cứu y tế khẩn cấp và mô phỏng phản xạ tình huống ứng dụng AI, hướng đến SDG 3 và Đề án cấp cứu ngoại viện tại Việt Nam.

## Cấu trúc Codebase
- `mobile/`: Ứng dụng di động đa nền tảng viết bằng Flutter.
- `backend/`: 
- `docs/`: Tài liệu đặc tả yêu cầu, thiết kế kiến trúc và minh chứng AI theo từng chương học phần.
